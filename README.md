# Smart ML Pipeline (PG Certificate Capstone)

Capstone project, Trimester 2, Post Graduate Certificate Program in Machine Learning, Vellore Institute of Technology (2023–2024). Author: Badrinarayan Nandakumar.

An end-to-end machine-learning pipeline in one notebook (`Final_Capstone_2_Trimester_2_SmartMLPipeline.ipynb`, also exported as a Python script). It covers data discovery, data cleaning, feature selection, several ML models, and a decision-tree builder that assembles sub-trees into a final tree, printed for interpretation.

**Skills:** Python · Pandas · scikit-learn · Feature selection · Decision trees · Model interpretation
